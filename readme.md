# 🏟️ Sports Borrowing System
ระบบยืม-คืนอุปกรณ์กีฬา สำหรับบุคลากรและนักศึกษา ออกแบบมาเพื่อความใช้งานง่าย รวดเร็ว และทันสมัย

## 🚀 Stack & Technologies
- **Backend:** PHP 8.x (PDO)
- **Database:** MySQL
- **Frontend:** Tailwind CSS, jQuery
- **Interaction:** AJAX, jQuery Confirm (Smooth UI)
- **Container:** Docker & Docker Compose

## 🐳 How to Run with Docker
1. Clone โปรเจกต์ลงในเครื่อง
2. ตรวจสอบไฟล์ `.env` สำหรับการตั้งค่า Database
3. รันคำสั่ง:
   ```bash
   docker-compose up -d
